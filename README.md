# Рядом — видеособеседования один на один

Статический сайт на HTML, CSS и JavaScript. Видеосвязь устанавливается через WebRTC, а обмен сигнализацией идёт через `wss://inai-col3.fishrungames.com/signaling/`.

## Запуск локально

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000`. Для доступа к камере используйте `localhost` или HTTPS. Чтобы проверить звонок, откройте сайт в двух браузерах или на двух устройствах.

## GitHub Pages

Workflow `.github/workflows/pages.yml` публикует сайт при каждом push в `main`. Если Pages ещё не настроен, в **Settings → Pages → Build and deployment** выберите **GitHub Actions**. После успешного запуска workflow сайт будет доступен по адресу `https://lazutinkirill468-dev.github.io/-9/`.

Сервер сигнализации соединяет только двух участников и не поддерживает отдельные комнаты. Для маршрутизации медиа между сетями, где прямое соединение ограничено, может понадобиться TURN-сервер; сейчас используется публичный STUN-сервер.
